# xc2fps (XC2_FPS60, on): the frame rate of the frame limit XC2_FPS_LIMIT (frame_rate.c). XC2 paces its frames as
# XCX 2.0.0 does (recomp/patches-upd.txt, set xcx60): a frame interval in vsyncs at main+0xb75c40, set to 2 at boot; a

# masagrator's Xenoblade2DynFPS (2.1.0, GPL-2.0, read for behaviour only) sets the same interval from the present
